Property Management Solution — How It Works

A quick tour of the doctypes, how they link together, and the day-to-day workflows. Version {{ app_version }}.

The core entities

Master
Property
A building or estate. Tree-structured (parent/child). Holds meter installations, amenities, insurance and on-site assets.
Master
Property Unit
An individually-leasable unit within a Property — apartment, office, shop. Carries occupancy status (Available / Rented / etc.).
Transaction
Lease
Tenancy agreement linking a Property + Customer + lease items + dates. Generates the invoice schedule and triggers handover checklists.
Generated
Sales Invoice
Issued automatically from the Lease Invoice Schedule at each cycle, or manually for utility / damage recoveries.
Operations
Issue
Maintenance ticket. Routes to the right vendor, tracks parts via Material Request, bills back through Sales Invoice.
Compliance
Property Document
Title deeds, insurance policies, fire-safety certificates etc. with expiry & renewal-reminder tracking.
Vendors
Property Vendor
Service providers (plumbing, electrical, security…) with agreement dates, value, rating, optional Supplier link.
Master
Insurance
Policies attached to a Property — coverage, premium, validity window.

Day-to-day workflows

1 · Onboard a new property

1
Create a parent Property for the building. Optionally create child Property records per floor, plus a Property Unit per leasable space.
2
Attach the title deed and any certificates as Property Documents, with the expiry date set so they show up in the “Expiring Soon” rollup.
3
Register meters under the Property's Property Meter Reading table (each row points to a Meter master).

2 · Sign a lease

1
Create a Lease: pick the Property + Customer + start/end dates + lease items (rent, service charge, etc.).
2
On Submit: the system auto-generates the Lease Invoice Schedule for every cycle and creates a Daily Checklist for Handover from the “Handover” checkup area template.
3
Property status flips to On Lease and, in the last 3 months, to Off Lease in 3 Months for renewal flagging (visible on the workspace).

3 · Billing

1
Every day at 12:00, propms.lease_invoice.leaseInvoiceAutoCreate walks Lease Invoice Schedule rows whose date_to_invoice is due and creates one Sales Invoice per (lease, customer, item group, date, currency) grouping.
2
Utility invoices are produced when a Meter Reading is submitted — one row per Property Unit, billed to the lease customer.
3
Watch Debtors Report and Rent Invoices Details from the workspace for collection status.

4 · Maintenance

1
Tenant or property manager opens an Issue with the Property field set. Assign a Person-in-charge (and optionally a Property Vendor).
2
Add the parts to Materials Required; a Material Request is generated. When marked Issued, a billable Sales Invoice draft is created for the tenant (if applicable).
3
Close the Issue with the Customer Feedback field; the Sales Invoice can be submitted by the maintenance manager.

5 · Move-out

1
Create an Exit record. Generate a Takeover Daily Checklist.
2
Reconcile the Security Deposit on the Lease — mark it Returned / Recovered for rent / Recovered for repairs.
3
Property status auto-flips back to Available the day after lease end.
